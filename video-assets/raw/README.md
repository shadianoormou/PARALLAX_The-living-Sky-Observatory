# PARALLAX raw demo recordings

These clips were captured from the public Vercel deployment in Chrome after enabling macOS Screen Recording permission. They are authentic browser footage for editing in the NASA submission video.

- `01-landing.mov` — landing page / mission hook
- `02-run-investigation.mov` — live investigation and processing status
- `03-epoch-comparison.mov` — repeated observation comparison
- `04-blink-difference.mov` — blink/difference exploration view
- `05-evidence-export.mov` — PARALLAX X evidence/mission brief
- `06-candidate-measurement.mov` — candidate queue and measurement context
- `07-provenance-source.mov` — provenance and source page
- `08-human-review.mov` — citizen/reviewer workflow
- `09-classroom-impact.mov` — classroom and adoption story
- `10-multiband-validation.mov` — validation workflow
- `11-artifact-rejection.mov` — science method and artifact rejection
- `12-production-evidence.mov` — production/evidence page

The `00-permission-test-*.mov` file is an internal capture test and should not be used in the final edit.

Important: the visible browser chrome is intentionally retained so the footage remains traceable to the public deployment. Gemini may crop the browser frame during editing, but must not invent or replace the application content.
